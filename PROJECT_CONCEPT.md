# PROJECT_CONCEPT.md

## 1. Название проекта
Карьерная траектория ЮГУ

---

## 2. Цель проекта
Создать веб-приложение для профориентации школьников и абитуриентов, которое помогает определить их склонности, интересы и на основе этого предлагает подходящие направления обучения в ЮГУ и возможную карьерную траекторию.

---

## 3. Целевая аудитория
- школьники (8–11 класс)
- абитуриенты
- люди, выбирающие профессию

---

## 4. Основной сценарий пользователя

1. Пользователь заходит на сайт
2. Заполняет анкету (возраст, класс, предпочтения и т.д.)
3. Проходит тест профориентации
4. Система анализирует ответы
5. Пользователь получает:
    - подходящие сферы
    - направления обучения в ЮГУ
    - карьерную траекторию
    - возможные профессии
    - навыки

---

## 5. Основная логика системы

Система работает по следующей цепочке:

АНКЕТА → ТЕСТ → БАЛЛЫ → СФЕРА → НАПРАВЛЕНИЕ → ПРОФЕССИЯ → КАРЬЕРНАЯ КАРТА

---

## 6. MVP (минимальная версия проекта)

В первую версию проекта входит:

- анкета пользователя
- тест профориентации
- система расчёта баллов
- определение сфер деятельности
- сопоставление с направлениями ЮГУ
- вывод результата
- отображение карьерной траектории

---

## 7. Что НЕ входит в MVP

- искусственный интеллект
- сложная адаптивная логика теста
- регистрация пользователей (опционально позже)
- сложная аналитика
- интеграции с внешними сервисами

---

## 8. Роли в системе

### Пользователь
- проходит тест
- получает результат

### Администратор (позже)
- добавляет вопросы
- управляет направлениями
- управляет профессиями

---

## 9. Основные сущности системы

- User (пользователь)
- Questionnaire (анкета)
- Question (вопрос)
- Answer (ответ)
- Result (результат теста)
- Field (сфера)
- Direction (направление ЮГУ)
- Profession (профессия)
- CareerPath (карьерная траектория)

---

## 10. Технологический стек

- Backend: Laravel (PHP)
- Frontend: Blade (на старте)
- База данных: MySQL
- Среда разработки: VS Code / PhpStorm
- Логика: балльная система (rule-based)

---

## 11. Архитектурный подход

- простая MVC-архитектура
- минимализм (без усложнений)
- ориентация на MVP
- постепенное расширение

---

## 12. Основной результат проекта

Пользователь должен получить:

- понимание своих склонностей
- список подходящих направлений в ЮГУ
- карьерную траекторию
- возможные профессии
- ориентир по развитию

---

## 13. Перспективы развития

- подключение психологических тестов
- улучшение логики рекомендаций
- добавление личного кабинета
- аналитика
- интеграция с вузом
