# Спецификация master-таблицы данных

Документ описывает структуру единой таблицы для хранения, ручной верификации
и импорта данных по образовательным программам, профессиям и учреждениям.

---

## Общая концепция

Таблица хранится в файле `docs/master-programs.csv` (либо Google Sheets).
Каждая строка — одна образовательная программа в конкретном учреждении
с конкретной формой обучения.

Одна программа с очной и заочной формой обучения — **две строки**.

---

## Уже существующий CSV-прототип

Файл `info_edu/programs.csv` содержит 106 строк с полями:

```
institution, city, study_form, code, name, level, spheres, school
```

Это основа таблицы. В спецификации ниже описаны все поля, которые
должны быть добавлены к этому прототипу.

---

## Блок 1 — Идентификация программы

| Столбец | Тип | Обязателен | Описание |
|---|---|---|---|
| `fgos_code` | строка | **да** | Код ФГОС: `09.03.01`, `21.02.01`, `1.2.2` и т.д. |
| `program_name` | строка | **да** | Официальное полное название программы |
| `level` | enum | **да** | `бакалавриат` / `специалитет` / `магистратура` / `аспирантура` / `СПО` |
| `study_form` | enum | **да** | `очная` / `заочная` / `очно-заочная` |

**Примечание:** Уникальный ключ строки = `fgos_code` + `institution_id` + `study_form`.
Одинаковый код в разных учреждениях или с разными формами → разные строки.

---

## Блок 2 — Учреждение

| Столбец | Тип | Обязателен | Описание |
|---|---|---|---|
| `institution_name` | строка | **да** | Полное официальное название учреждения |
| `institution_short` | строка | нет | Аббревиатура: ЮГУ, МПК, ЛНТ и т.д. |
| `institution_type` | enum | **да** | `университет` / `институт` / `колледж` / `техникум` / `филиал` |
| `city` | строка | **да** | Город: `Ханты-Мансийск`, `Сургут`, `Лянтор`, `Нижневартовск`, `Нефтеюганск` |
| `school_department` | строка | нет | Школа/факультет внутри вуза (только для ЮГУ) |

---

## Блок 3 — Классификация (сферы)

| Столбец | Тип | Обязателен | Описание |
|---|---|---|---|
| `spheres` | строка | **да** | Сферы через `\|`: `IT\|Техника`, `Естественные науки` и т.д. |
| `primary_sphere` | строка | нет | Главная сфера (первая в списке). Вычисляется при импорте |

Допустимые значения `spheres`:
`IT`, `Техника`, `Естественные науки`, `Здоровье`,
`Гуманитарные`, `Социальные`, `Педагогика`, `Экономика`, `Право`

---

## Блок 4 — Описание (контент)

| Столбец | Тип | Обязателен | Описание |
|---|---|---|---|
| `description` | строка | нет | Краткое описание программы (2–4 предложения) |
| `what_you_learn` | строка | нет | Чему учат: ключевые дисциплины или компетенции |
| `where_work` | строка | нет | Где работают выпускники: отрасли, типы работодателей |

**Статус сейчас:** все три поля пустые у всех 93 программ в сидере.
Это первый приоритет наполнения.

---

## Блок 5 — Профессии

| Столбец | Тип | Обязателен | Описание |
|---|---|---|---|
| `professions` | строка | нет | Профессии через `\|`: `Программист\|DevOps-инженер\|Аналитик данных` |

**Правило:** не менее 2 и не более 5 профессий на программу.
Профессии должны быть конкретными должностями, а не областями.

Примеры корректных профессий:
- `Разработчик программного обеспечения`
- `Инженер-нефтяник`
- `Юрист`

Примеры некорректных (слишком широких):
- `Специалист` (без уточнения)
- `Научный сотрудник`
- `Технологический предприниматель`

**Статус сейчас:** у 28 программ (все аспирантуры + часть магистратур)
профессии отсутствуют полностью.

## Блок 6 — Приёмная кампания (реальные цифры)

Эти данные берутся из официального сайта ЮГУ
(файл `info_edu/school_YUGU.txt` и аналоги для СПО).

| Столбец | Тип | Обязателен | Описание |
|---|---|---|---|
| `budget_seats_rf` | число | нет | Бюджетные места (федеральные) |
| `budget_seats_hmao` | число | нет | Бюджетные места (региональные, ХМАО-Югра) |
| `commercial_seats` | число | нет | Платные (внебюджетные) места |
| `target_seats` | число | нет | Целевые места |
| `applications_2025` | число | нет | Число заявлений на 2025 год (из файлов приёмки) |
| `competition_rate` | число | нет | Конкурс: заявлений на место (из файлов приёмки) |

**Примечание:** Данные приёмной кампании 2025 уже частично
доступны в `info_edu/school_YUGU.txt` и других `.txt`-файлах.
Требуется разбор и перенос в таблицу.

## Блок 7 — Верификация

| Столбец | Тип | Обязателен | Описание |
|---|---|---|---|
| `verified` | boolean | **да** | `TRUE` / `FALSE` — проверена ли строка по официальному источнику |
| `source_url` | строка | нет | Ссылка на страницу программы на сайте учреждения |
| `verified_by` | строка | нет | Кто проверял: имя или инициалы |
| `verified_date` | дата | нет | Дата последней проверки (ГГГГ-ММ-ДД) |
| `notes` | строка | нет | Произвольные пометки: устаревшая, ускоренная, новая и т.д. |

## Итоговая структура (порядок столбцов)

```
fgos_code, program_name, level, study_form,

applications_2025, competition_rate,
verified, source_url, verified_by, verified_date, notes
```

Итого: **26 столбцов**, из них **6 обязательных**.

---

## Правила ведения таблицы

1. Каждая строка — уникальная комбинация `fgos_code + institution_name + study_form`.
2. Значения `spheres` разделяются символом `|` без пробелов: `IT|Техника`.
3. Значения `professions` разделяются символом `|` без пробелов.
4. Булевые поля: `TRUE` / `FALSE` (заглавными буквами).
5. Даты в формате `ГГГГ-ММ-ДД`: `2025-04-10`.
6. Пустые значения — пустая ячейка (не `NULL`, не `0`, не прочерк).
7. Кириллица в названиях — обязательна (кроме англоязычных программ).

## Статусы верификации (поле `notes`)

Рекомендуемые стандартные метки:

| Метка | Значение |
|---|---|
| `ok` | Проверена, данные актуальны |
| `needs_description` | Нет описания программы |
| `no_professions` | Не заполнены профессии |
| `check_seats` | Нужно уточнить места/конкурс |
| `outdated` | Программа могла измениться |
| `removed` | Программа больше не ведётся (строку оставить, не удалять) |
| `new_2025` | Новая программа, не было в предыдущем наборе |

## Что делать с этой таблицей дальше

### Шаг 1 — Создать `master-programs.csv`
Взять `info_edu/programs.csv` как основу, добавить недостающие столбцы,
заполнить `verified = FALSE` для всех строк.

### Шаг 2 — Перенести данные приёмки
Разобрать `.txt`-файлы из `info_edu/` и заполнить столбцы
`budget_seats_rf`, `budget_seats_hmao`, `commercial_seats`, `applications_2025`.

### Шаг 3 — Заполнить описания и профессии
Приоритет: программы ЮГУ бакалавриат/специалитет (высокий трафик).
Затем: магистратуры и аспирантуры (нет профессий — блок пустой).

### Шаг 4 — Пометить верифицированные строки
После ручной проверки по сайту учреждения: `verified = TRUE`.

### Шаг 5 — Импорт в проект
Написать Artisan-команду `php artisan import:programs docs/master-programs.csv`,
которая читает CSV и обновляет/создаёт записи в БД через Eloquent upsert.
